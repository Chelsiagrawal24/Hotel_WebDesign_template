# Hotel Website

A responsive and modern hotel website designed to showcase hotel services, rooms, amenities, and booking information. This project demonstrates front-end web development skills using HTML, CSS, and JavaScript.

## 📖 Project Overview

The Hotel Website is a user-friendly web application that allows visitors to:

- View hotel information
- Explore room categories
- Check amenities and services
- Browse image galleries
- Contact the hotel
- Make booking inquiries

The website is designed with a clean interface and responsive layout to provide an excellent user experience across desktop, tablet, and mobile devices.

## 🚀 Features

- Responsive Design
- Attractive Homepage
- Room Listings
- Hotel Amenities Section
- Image Gallery
- Contact Form
- Navigation Menu
- Smooth Scrolling Effects
- Mobile-Friendly Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap (if used)
